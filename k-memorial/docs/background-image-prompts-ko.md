# k-memorial 숨은그림찾기 배경 이미지 프롬프트 30종

## 공통 제작 기준

- 용도: 고난도 숨은그림찾기 게임의 음식 없는 배경 원본
- 화면비: 가로 16:9
- 표현: 사실적인 한국 로케이션 사진, 과도한 HDR이나 판타지풍 금지
- 카메라: 사람 눈높이보다 약간 높은 시점, 24~28mm 광각, 수평·수직 왜곡 최소화
- 초점: 전경부터 배경까지 알아볼 수 있는 deep focus
- 구성: 전경·중경·배경에 작은 오브젝트가 많고 겹침이 풍부한 복잡한 화면
- 상태: 영업 시작 전 또는 영업 종료 직후, 사람과 음식이 없는 정돈된 식당
- 절대 금지: 완성된 음식, 식재료, 과일, 채소, 고기, 생선, 해산물, 곡물, 떡, 전, 나물, 국, 밥, 음료
- 수집 오브젝트 금지 목록: 병풍, 신위, 술잔, 밥, 국, 수저, 국수, 육적, 소적, 어적, 떡, 육전, 육탕, 소탕, 어탕, 어전, 포, 삼색나물, 간장, 침채 또는 나박김치, 식혜, 대추, 밤, 배, 감 또는 곶감, 사과, 강정, 향로, 향합, 술병, 퇴주잔
- 기타 금지: 사람, 얼굴, 인물 사진, 제사상, 영정, 신위, 읽을 수 있는 글자, 메뉴판 문구, 상호, 로고, 상표, 워터마크
- 안전 영역: 우측 18%에는 핵심 장식이나 강한 초점 요소를 두지 않아 미니맵 UI가 올라갈 수 있게 구성

> 아래 프롬프트는 각각 별도의 이미지 생성 요청으로 사용한다. 한 번의 요청에서 여러 장소를 콜라주로 만들지 않는다.

```text

Scene/backdrop: 넓은 창밖으로 잔잔한 저수지, 겨울 철새, 억새와 왕버들이 보이고, 실내에는 목재 테이블, 빈 회전식 꼬치 화로, 숯 바구니, 방석, 황토 벽, 오래된 선풍기와 탐조용 망원경이 놓여 있다

Composition/framing: 가로 16:9, 사람 눈높이보다 약간 높은 24mm 광각, 전경의 빈 화로부터 창밖 저수지까지 깊이감 있는 복잡한 구성, 우측 18%는 미니맵 UI 안전 영역

Detail targets: 숯 조각, 꼬치대, 방석 문양, 창틀, 억새, 망원경, 장작과 작은 생활 소품으로 숨길 구역을 풍부하게 만든다
```
