# k-memorial 제품 계획

## 1단계: Basic 30

한국의 음식문화 장소 30곳을 배경으로 하는 기본 숨은그림찾기 게임을 먼저 완성한다. 각 스테이지는 별도의 음식 없는 배경 이미지와 음식 오브젝트 레이어를 사용한다.

### 고정 제작 원칙

- 30개 모두 가로형 16:9, 동일한 시점과 품질
- 숨길 제수 음식은 배경에 절대 등장시키지 않기
- 빈 그릇·조리도구·가구·장식·지역 특산 소재로 화면 밀도 확보
- 글자가 읽히는 간판, 상표, 로고, 인물은 제외
- 화면 전체에 숨길 공간을 만들되 가장자리는 UI에 가리지 않도록 구성
- 전경·중경·배경에 각각 오브젝트를 놓을 수 있게 깊이 확보
- 원본 배경과 음식 오브젝트를 완전히 별도 레이어로 관리

### 기본 플레이 구조

1. 지역 음식점 배경에서 제수 음식 5개를 찾는다.
2. 돋보기는 배경과 음식 레이어를 함께 확대한다.
3. 미니맵은 정확한 위치가 아니라 넓은 탐색 구역만 알려준다.
4. 찾은 음식의 한국어·영어 문화 카드를 수집한다.
5. 수집한 음식으로 상차림 규칙 퍼즐을 완성한다.

## 2단계: Maker Community

메이킹 플레이어가 생성형 AI로 음식점 배경을 만들고, 음식 오브젝트를 직접 커스터마이징한 뒤 숨은그림찾기 스테이지를 게시한다.

### 메이커 도구

- 음식점 배경 생성
- 음식 이미지 업로드 또는 생성
- 색상 제거, 채도 조절, 단색화
- 윤곽선 전용 표현
- 크기, 회전, 투명도, 블렌딩 조절
- 배경의 전경·중경·후경 레이어 지정
- 클릭 영역과 힌트 구역 설정
- 테스트 플레이와 난이도 측정
- 커뮤니티 게시 및 컬렉션 등록
